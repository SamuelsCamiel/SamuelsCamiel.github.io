Ik leer al 4 jaar HTML en CSS op het Grafisch Lyceum Rotterdam en zelf ook al een tijdje wat ervoor heeft gezorgd dat ik een goeie basis heb en goed begrijp hoe de code werkt op een basislevel. Naast de talen zelf heb ik ook ervaring met Bootstrap en Tailwind wat veel tijd bespaart bij het maken van een front-end voor websites. Verder ben ik ook al 3 jaar bezig met Javascript. Het is namelijk erg handig om te weten omdat er veel systemen, websites, frameworks en meer gebaseerd zijn op Javascript of er gebruik van maken. Ik ben ook al bekend met verschillende Javascript libraries en compilers zoals P5.JS voor animaties en kunst, Leaflet voor interactieve kaarten, jQuery voor DOM manipulatie en het handelen van events en Typescript wat handig is voor grote projecten omdat typescript een statisch getypeerde taal is wat betekent dat alles strict gedefinieerd is en errors al gecheckt worden bij het compilen en niet wanneer de code geexecuteerd word. Ook leer ik ook al 1,5 jaar PHP en SQL wat handig is om te weten omdat je met PHP veel meer dynamische elementen kan maken. Daarnaast zijn PHP en SQL heel belangrijk om te weten zodat je kan werken met databases.
